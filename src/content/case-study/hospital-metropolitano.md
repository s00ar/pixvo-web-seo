overview:
  image: "/images/case-study/hospital-metropolitano/hospital-metropolitano.jpg"
  title: "Resumen"
  content: |
    El caso se presenta como experiencia asociada al trabajo de Santiago y del equipo, no como un cliente directo atribuible a Pixvo. El producto aborda la dispersión de formularios, mensajes, emails, planillas, certificados y contenidos que debían reconstruirse para cada evento.
    
    La gestión de eventos combinaba formularios, WhatsApp, emails, planillas y documentos separados. Agenda, participantes, certificados y materiales recorrían canales distintos.

challenges:
  title: "Desafío"
  content: |
    Cada nuevo evento obligaba a repetir configuraciones y controles. La información para asistentes y la operación interna no compartían una única capa de datos ni permisos.
    
    La dispersión aumentaba la cantidad de puntos que el equipo debía revisar y hacía más difícil reutilizar la estructura operativa de un evento en el siguiente.
  quote: "No se atribuye el proyecto directamente a Pixvo: es experiencia asociada del equipo y no hay evidencia independiente suficiente para publicar cifras de asistentes, ahorro, tiempos o productividad."
  quote_author:
    name: "Equipo Pixvo"

    avatar: "/images/isotipo.png"

solution:
  image: "/images/case-study/hospital-metropolitano/hospital-metropolitano.jpg"
  title: "Solución"
  content: |
    El alcance documentado reúne una aplicación mobile, un backoffice web y una capa compartida de backend y datos para gestionar eventos, agenda, expositores, posters, documentos, videos, auspiciantes, avales, stands, mapas e inscritos.
    
    Mobile y web comparten backend y capa de datos. La separación entre experiencia de asistentes y backoffice permite utilizar interfaces distintas sin volver a fragmentar la información.
    
    Atribución: la atribución pública del proyecto corresponde a Metamorfosis 360 y Events Group. Pixvo lo presenta únicamente como experiencia asociada al trabajo de Santiago y del equipo.
  items:
    - "Aplicación mobile, backoffice web y capa de datos compartida"
    - "Gestión de agenda, expositores, posters, documentos, videos, auspiciantes, avales, stands y mapas"
    - "Inscritos, autenticación, roles, compatibilidad legacy, CI y búsqueda"

results:
  title: "Resultados"
  content: |
    La transformación funcional es una operación de eventos más integrada: contenidos para asistentes y tareas administrativas se apoyan en el mismo sistema y en una estructura reutilizable.
    
    Nota: no se atribuye el proyecto directamente a Pixvo. El workspace no aporta evidencia independiente suficiente para publicar un evento concreto como validación, ni cifras de asistentes, ahorro, tiempos o productividad.
