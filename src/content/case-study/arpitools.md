overview:
  image: "/images/case-study/arpitools/arpitools-card.png"
  title: "Resumen"
  content: |
    Arpitools separa las interfaces según el contexto de uso sin fragmentar el ecosistema: mobile concentra las herramientas operativas y web ofrece el espacio necesario para consulta y reporting.
    
    La operación diaria y el análisis posterior necesitaban superficies diferentes. Forzar ambas tareas en una única interfaz limitaba la experiencia de uso.

challenges:
  title: "Desafío"
  content: |
    Las herramientas operativas debían estar disponibles en mobile, mientras que consultas, tablas y reportes requerían una superficie web complementaria y coherente.
    
    Sin una separación clara por contexto, la interacción cotidiana y el reporting competían dentro del mismo recorrido y podían fragmentar acceso e información.
  quote: "No se publican mejoras de productividad, tiempos, usuarios, volumen de operaciones ni resultados comerciales: lo verificable es la decisión de producto de separar mobile y web por contexto de uso."
  quote_author:
    name: "Equipo Pixvo"
    designation: "Nota editorial sobre los datos"
    avatar: "/images/isotipo.png"

solution:
  image: "/images/case-study/arpitools/arpitools-card.png"
  title: "Solución"
  content: |
    Se desarrolló una aplicación mobile para las herramientas de uso diario y una aplicación web complementaria para consultar información y generar reportes dentro del mismo producto.
    
    La decisión arquitectónica central es separar mobile y web por contexto de uso, manteniéndolos dentro de un mismo ecosistema.
  items:
    - "Aplicación mobile orientada a la operación diaria"
    - "Aplicación web complementaria para consulta y reporting"
    - "Complementariedad funcional entre las superficies mobile y web"

results:
  title: "Resultados"
  content: |
    La transformación verificable es de producto: dos superficies coordinadas responden a tareas distintas, operación mobile y reporting web, sin inferir mejoras de productividad.
    
    Nota: no se publican mejoras de productividad, tiempos, usuarios, volumen de operaciones, resultados comerciales ni atribuciones individuales adicionales.
