## Problema

La solicitud de crédito requería un recorrido móvil más claro, validaciones inmediatas y una integración que evitara trasladar manualmente la información al proceso comercial.

## Objetivos

- Simplificar la solicitud desde dispositivos móviles
- Validar datos y cualificar perfiles en tiempo real
- Enviar oportunidades a Clientify y preparar la medición publicitaria

## Estrategia

Se diseñó un formulario por pasos con campos condicionales, estados de error comprensibles y una capa de integración desacoplada.

## Solución

Frontend ReactJS con validación dinámica de CUIL, monto y situación laboral, React Context y envío mediante webhook/API a Clientify.

## Tecnologías

- React
- React Context
- Clientify
- Webhooks
- Google Ads
- Meta Pixel
