# Decisiones y datos pendientes

No bloquean el build, pero sí las funciones indicadas:

- Precios mensuales y onboarding aprobados en MXN para México.
- Precios mensuales y onboarding aprobados en USD para Argentina.
- Avisos fiscales por mercado.
- Identidad fiscal, domicilio, responsable, base jurídica, conservación y canal de derechos para textos legales definitivos.
- Identificador GTM aprobado y configuración del contenedor.
- Herramienta y configuración de consentimiento si se activan cookies no necesarias.
- Integración de confirmación interna/email y reglas privadas de calificación.
- URL de calendario; solo debe entregarse después de calificación privada.
- Casos, métricas, logos y autorizaciones verificables antes de publicar prueba social.

El sitio oculta importes no aprobados y no publica placeholders. Las páginas legales permanecen `noindex` mientras faltan datos definitivos.
